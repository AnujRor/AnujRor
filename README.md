## 🚀 What drives me

I grew up in Harsola, a small village in Haryana, where building artificial intelligence felt like a distant dream. I decided to learn it anyway.

I'm not here to write code that just works. I'm here to build something that outlasts me — something people keep using long after I'm gone.

Every project I start, I ask the same question: *could this be the one that changes something?* Most won't be. That's fine. You don't find the one without building the other hundred.

So I build. A lot. And I ship it publicly, even when it's rough.

## 🧭 How I work

- **I take risks.** Comfortable projects teach you nothing. If I already know how it will turn out, it's probably not worth building.
- **I explore.** New stacks, new tools, new problems — chasing unfamiliar things is my favourite part. Web, backend, voice AI, AI agents; I go wherever the interesting problem is.
- **I ship.** An unfinished idea helps no one. Done and public beats perfect and hidden.

## 📌 Featured

### 🎙️ AI Dost — Voice AI Companion
A voice companion that feels like a real-life friend. You talk, it listens, understands and talks back naturally — in real time.

The interesting part is the voice pipeline: **LiveKit** handles the real-time audio, **Deepgram** turns speech into text, **OpenAI** thinks, and **ElevenLabs** speaks the reply back.

 · 📦 [Code](https://github.com/AnujRor/ai-dost)

### 🤖 Portfolio Chat Bot
